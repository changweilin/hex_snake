# Q 版立繪附加效果 Prompt 備忘

用途：下一輪重新生成「背景透明」的 Q 版附加效果立繪。角色本體需保留目前初始 Q 版造型，只加入各自風格效果。

## 共通要求

- 以各角色初始 Q 版立繪為 edit target。
- 保留角色本體：姿勢、比例、臉、眼睛、線稿、配色、主要輪廓不可改。
- 輸出需為透明背景 PNG。
- 不要產生紫色、洋紅色、綠色或任何 chroma-key 底色。
- 透明像素需是真 alpha 透明，不要把透明色殘留成紫色 RGB。
- 透明處理要把紫色清乾淨：角色與效果邊緣不可有紫色 fringe、紫色光暈不可被誤當背景殘留；若效果本身使用紫色，必須只保留可見雷電/靈氣筆觸，周圍空白仍為 alpha 0 且 RGB 為 0,0,0。
- 效果必須是 Q 版、遊戲立繪風格、可愛且精緻，不可寫實。
- 效果不可遮住臉、眼睛或角色主要身體辨識區。
- 除智蝦外，皆參考智蝦鬼魂效果的呈現方法：效果以半透明靈氣、薄霧、光點或符號層在角色周圍環繞，部分元素在角色前方，部分元素在角色後方，但不可改動角色本體。
- 只生成角色周圍附加效果與必要接觸陰影，不生成完整場景、地面、天空或色塊背景。
- 不要文字、浮水印、邊框、完整場景背景。

## 白龍

以 `assets/portraits/white_dragon_chibi.png` 為 edit target，保留白龍初始 Q 版。參考智蝦鬼魂效果的做法，在角色周圍加入半透明白雲與陽光環繞效果：柔軟白雲分布在下方與側邊，金色陽光光束、金色光點與星芒繞著身體前後穿插。密度保持清爽，不要過多雲層或滿版閃光。背景必須保持真 alpha 透明。
