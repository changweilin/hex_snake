# 角色語音與音效設計

## 共通原則
- 語音與音效長度需**簡短**，以讀取速度為優先。
- 「幻獸版」與「Q獸版」共用相同的野獸音效版本。
- 「擬人版」使用符合角色性格與故事背景的女性配音，搭配對應的各國語言，並在小招與大招時疊加幻獸版的技能音效。

---

## 幻獸版 / Q獸版 (野獸音效)
**觸發情境**：
- **被選擇 / 遊戲開始 / 勝利 / 失敗**：使用符合角色原型與使用情境的野獸/怪物叫聲（參考真實動物或奇幻/科幻電影）。
- **小招 / 大招**：根據角色元素與招式特徵製作音效。

### 智蝦 (Smart Shrimp)
- **原型參考**：深海異種、靈異現象
- **被選擇**：低沉的深海氣泡聲混雜空靈的回音。
- **開始**：短促且帶有威懾力的水底低鳴。
- **小招 (連續鬼火)**：連續幾聲輕盈且詭異的「呼、呼」火焰燃燒聲，帶有冷色調的靈異回音。
- **大招 (爆發重拳)**：沉重且震撼的「砰！」打擊聲，伴隨水壓爆裂的沉悶低音。
- **勝利**：悠長且具統治力的海怪長嘯。
- **失敗**：水泡破裂與漸弱的嘶嘶聲。

### 白龍 (White Dragon)
- **原型參考**：東方神龍、冰雪神獸
- **被選擇**：清脆的冰晶碎裂聲伴隨空靈的龍吟。
- **開始**：高亢且帶有寒氣的昂揚龍嘯。
- **小招 (瞬間凍結)**：銳利且迅速的「喀啦」結冰聲。
- **大招 (持續寒氣)**：呼嘯的凜冽暴風雪聲，夾雜著冰塊不斷凍結的細碎聲響。
- **勝利**：清亮入雲的龍吟，伴隨風雪平息的微音。
- **失敗**：沉悶的龍喘息，伴隨冰層大面積碎裂瓦解的聲音。

### 電鰻 (Electric Eel)
- **原型參考**：深海電鰻、雷電魔獸
- **被選擇**：高頻的「劈啪」電流聲，帶點危險的滋滋作響。
- **開始**：如高壓電弧激發的尖銳鳴叫。
- **小招 (雷電)**：短促且明亮的「啪滋！」電擊聲。
- **大招 (狂雷)**：轟鳴的雷聲疊加連續且密集的狂暴電流聲。
- **勝利**：充滿活力的電流脈衝聲，規律且清脆。
- **失敗**：如同電力耗盡般，逐漸微弱並「啵」一聲熄滅的短路聲。

### 沙蟲 (Sand Worm)
- **原型參考**：沙漠巨蟲、科幻巨獸
- **被選擇**：沉悶的地鳴聲與沙礫滑動的摩擦聲。
- **開始**：令人毛骨悚然的巨蟲嘶吼，伴隨地表的震動感。
- **小招 (打擊前置地鳴)**：低頻隆隆作響的地鳴聲，彷彿地底有巨大物體在快速移動。
- **大招 (破土岩崩)**：劇烈且震撼的「轟隆！」破土聲，伴隨大量岩石崩落與沙塵飛揚的巨響。
- **勝利**：震耳欲聾的勝利咆哮，隨後是潛入沙中的沉重摩擦聲。
- **失敗**：痛苦的嘶鳴，最後是重物砸落地面的悶響。

### 羽蛇 (Quetzalcoatl)
- **原型參考**：阿茲特克神獸、風之靈鳥
- **被選擇**：清脆的鳥鳴聲與翅膀拍打風的聲音。
- **開始**：嘹亮、神聖且充滿生機的猛禽/蛇嘶混合音。
- **小招 (叢林婆娑)**：輕柔但急促的「沙沙」樹葉摩擦聲與風聲。
- **大招 (持續狂風)**：強烈且持續的狂風呼嘯聲，夾雜著猶如暴風雨中樹林搖曳的巨響。
- **勝利**：悠揚的長鳴，伴隨輕盈風鈴般的聲響。
- **失敗**：哀傷的短鳴，以及羽毛散落的微風聲。

### 蠱王 (Gu King)
- **原型參考**：異形、毒蟲集合體
- **被選擇**：黏膩的液體滴落聲與多重昆蟲節肢爬行的「窸窣」聲。
- **開始**：尖銳刺耳的異形嘶嘶聲，帶有多重聲道的重疊感。
- **小招 (毒液噴吐)**：短促且帶有腐蝕感的「噗嗤」噴灑聲。
- **大招 (多次噴吐)**：連續的「噗嗤、噗嗤」毒液狂噴聲，結尾伴隨一聲毒包炸裂的黏稠爆裂聲。
- **勝利**：令人不安的蟲鳴大合唱與詭異的咔噠咔噠聲。
- **失敗**：黏液沸騰乾涸的聲音與一聲淒厲的尖叫。

## 擬人版 (配音設計)
**觸發情境與台詞要求**：
- **被選擇**：對應「好耶」
- **開始**：對應「出發」
- **小招**：對應「嘿」 + **對應幻獸版小招音效**
- **大招**：對應「喝」 + **對應幻獸版大招音效**
- **勝利**：對應「輕鬆」
- **失敗**：對應「怎麼可能」
- **特質**：統一採用符合角色性格的女性聲音，語氣需符合不同的使用情境。

### 白龍 (台灣中文)
- **性格**：高冷、優雅、帶點傲氣的仙女。
- **被選擇**：好耶！ (語氣優雅中帶著一點自信的喜悅)
- **開始**：出發。 (語氣堅定、清冷)
- **小招**：嘿！ + [瞬間凍結音效] (輕巧俐落)
- **大招**：喝！ + [持續寒氣音效] (氣勢磅礡、清脆有力)
- **勝利**：輕鬆。 (嘴角微揚，帶點游刃有餘的傲嬌感)
- **失敗**：怎麼可能... (語氣驚愕、難以置信)

### 電鰻 (日文)
- **性格**：活潑、元氣、帶點電波系的少女。
- **被選擇**：やった！ (Yatta! / 語氣非常興奮、活力四射)
- **開始**：出発！ (Shuppatsu! / 語氣高昂、準備大鬧一場)
- **小招**：えい！ (Ei! / 嘿) + [雷電音效] (可愛且短促)
- **大招**：はあっ！ (Haa! / 喝) + [狂雷音效] (充滿能量的元氣釋放)
- **勝利**：楽勝！ (Rakushō! / 輕鬆) (語氣調皮得意)
- **失敗**：嘘でしょ... (Uso desho... / 怎麼可能) (語氣委屈、不敢相信)

### 智蝦 (英文)
- **性格**：冷靜、知性、帶有神秘感的御姐/學者。
- **被選擇**：Great. (語氣平靜、帶有一絲滿意的微笑)
- **開始**：Let's go. (語氣沉穩、成竹在胸)
- **小招**：Ha. (嘿) + [連續鬼火音效] (短促且冷酷)
- **大招**：Hah! (喝) + [爆發重拳音效] (充滿力量與爆發感的喝斥)
- **勝利**：Too easy. (語氣淡定、理所當然)
- **失敗**：Impossible... (語氣低沉、充滿疑惑與錯愕)

### 沙蟲 (阿拉伯文)
- **性格**：狂野、強悍、沙場女戰士。
- **被選擇**：ممتاز (Mumtāz / 極好) (語氣低沉有力、充滿戰意)
- **開始**：انطلاق (Inṭilāq / 出發) (語氣豪邁、充滿野性)
- **小招**：هيا (Hayyā / 嘿) + [地鳴音效] (粗獷且具侵略性)
- **大招**：خذ (Khudh / 喝/接招) + [破土岩崩音效] (震撼的戰吼)
- **勝利**：بسهولة (Bishūlah / 輕鬆) (語氣霸氣、不屑一顧)
- **失敗**：مستحيل (Mustaḥīl / 怎麼可能) (語氣憤怒、不甘心)

### 羽蛇 (西班牙文)
- **性格**：熱情、神聖、帶有拉丁風情的舞者/祭司。
- **被選擇**：¡Genial! (好耶) (語氣熱情奔放、充滿喜悅)
- **開始**：¡Vamos! (出發) (語氣輕快、像是在邀請跳舞)
- **小招**：¡Eh! (嘿) + [叢林婆娑音效] (輕快明亮)
- **大招**：¡Hah! (喝) + [持續狂風音效] (充滿節奏感與爆發力)
- **勝利**：¡Fácil! (輕鬆) (語氣愉悅、彷彿剛結束一場完美的表演)
- **失敗**：¿Cómo es posible? (怎麼可能) (語氣戲劇化、充滿驚訝)

### 蠱王 (韓文)
- **性格**：腹黑、病嬌、語氣詭異且危險的少女。
- **被選擇**：좋아~ (Joa~ / 好耶) (語氣拉長、帶有一點危險的愉悅感)
- **開始**：가볼까? (Gabolkka? / 出發吧) (語氣輕飄飄的、令人發毛)
- **小招**：얍! (Yap! / 嘿) + [毒液噴吐音效] (短促但帶著詭異的笑意)
- **大招**：하앗! (Ha-at! / 喝) + [多次噴吐音效] (帶著一點瘋狂與興奮的喊叫)
- **勝利**：시시하네~ (Sishihane~ / 輕鬆/無聊) (語氣慵懶、充滿輕蔑)
- **失敗**：말도 안 돼... (Maldo an dwae... / 怎麼可能) (語氣變得尖銳、無法接受現實的扭曲感)
