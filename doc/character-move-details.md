# 六角貪食蛇角色招式細節表

格式版本：1
最後更新：2026-05-08
資料來源：data/characters.json、data/balance.json、src/game.js、tools/sim-core.js

## 維護規則

每次調整角色招式數值或設計時，必須同步更新本文件。

需要更新的變更包含：

| 變更類型 | 範例 |
| --- | --- |
| 成本 | 小招/大招食物庫存、炸彈、能量門檻 |
| 時間 | 施放延遲、冷卻、脈衝間隔、持續時間、tick 間隔 |
| 形狀 | 圓形、線形、蛇身軌跡、頭部跟隨、半徑、寬度 |
| 傷害 | 基礎傷害、倍率、定額傷害、距離衰減、持續傷害總量 |
| 控制 | 暈眩、緩速、麻痺、堆疊、打斷 |
| 瞄準 | 使用瞄準點、目前面向、穿透、第一命中、追蹤自身頭部 |
| 安全性 | 是否自傷、是否排除自身蛇身、是否影響雙方 |
| 食補 | 食物生成偏好、迷幻菇、能量或庫存收益 |

## 全域戰鬥規則

| 項目 | 目前數值 |
| --- | --- |
| 所有招式是否自傷 | 否 |
| HP 上限 | （蛇長 + 1）× 2 |
| 小招成本 | 1 枚炸彈，並從目前最高的食物庫存 -2 |
| 大招成本 | 2 枚炸彈，蛋白質、脂肪、纖維素、碳水庫存各 -2 |
| 炸彈充能 | 6 能量獲得 1 枚炸彈，最多 3 枚 |
| 一般食物能量 | 2 |
| 迷幻菇能量 | 3 |
| 小招延遲 | 攻擊延遲 * 0.31 |
| 大招延遲 | 預設為攻擊延遲，部分角色覆寫 |
| 小招半徑 | max(1, 爆炸半徑 - 1) |
| 大招半徑 | 預設為爆炸半徑，部分角色覆寫 |
| 小招傷害 | 基礎傷害 * 0.5 |
| 大招傷害 | 預設為傷害倍率，部分角色覆寫 |
| 攻擊冷卻 | 基礎攻擊冷卻 / 攻擊速度倍率 |
| 小招冷卻 | 攻擊冷卻 * 0.29 |
| 大招冷卻 | 攻擊冷卻 |
| 暈眩率 | 身體命中且頭未命中：15%，每點碳水（藍色）+1%，最多額外 +20%；頭部命中：30%，每點碳水 +2%，最多額外 +40% |
| 暈眩時間 | 500ms 暈眩，接著 500ms 緩速 |
| 控制打斷 | 暈眩與麻痺會移除尚未命中的招式；打斷不重置該招式冷卻 |

## 食物加成

| 食物 | 代號 | 目前效果 |
| --- | --- | --- |
| 蛋白質（紅色） | protein | 爆炸半徑倍率每點 +0.05，預設最多 +1.0 |
| 脂肪（黃色） | fat | 傷害倍率基礎 2，每點 +0.07，最多額外 +1.4 |
| 纖維素（綠色） | fiber | 移動速度倍率每點 +0.04，最多額外 +0.8 |

| 迷幻菇 | black | 隨機蛋白質、脂肪、纖維素、碳水庫存 +1，並獲得 3 能量 |
