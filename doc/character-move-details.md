## 維護規則

每次調整角色招式數值或設計時，必須同步更新本文件。

需要更新的變更包含：

| 變更類型 | 範例 |
| --- | --- |
| 成本 | 小招/大招食物庫存、炸彈、能量門檻 |
| 時間 | 施放延遲、冷卻、脈衝間隔、持續時間、tick 間隔 |
| 形狀 | 圓形、線形、蛇身軌跡、追蹤拳路、半徑、寬度 |
| 傷害 | 基礎傷害、倍率、距離衰減、持續傷害總量 |
| 控制 | 暈眩、緩速、麻痺、易傷、堆疊、打斷 |
| 瞄準 | 目標點、方向、拖曳起點、蛇身軌跡、追蹤規則 |
| 安全性 | 是否自傷、是否排除自身蛇身、免疫窗口 |
| 食補 | 食物生成偏好、蟠桃、迷幻菇、能量或庫存收益 |

## 全域戰鬥規則

| 項目 | 目前數值 |
| --- | --- |
| 所有招式是否自傷 | 否；命中結算時會將施放者自己的傷害歸零 |
| HP 上限 | （蛇長 + 1）× 10 |
| 吃食回復 | 吃到食物會增加 1 段蛇身，並回復 10 HP，不超過 HP 上限 |
| 小招成本 | 1 枚炸彈，並從目前最高的食物庫存 -2 |
| 大招成本 | 2 枚炸彈，且蛋白、脂肪、纖維、碳水四種庫存各 -2 |
| 滿能量補彈 | 若能量已滿且炸彈也已滿，施放消耗炸彈的招式後，會立刻把滿能量轉成 1 枚炸彈 |
| 炸彈充能 | 6 能量獲得 1 枚炸彈，最多 3 枚；炸彈已滿時能量停在 6 |
| 一般食物能量 | 2 |
| 迷幻菇能量 | 3 |
| 單色食物庫存 | 同色庫存 +2 |
| 蟠桃(雙色)庫存 | 顯示的兩種庫存各 +1 |
| 迷幻菇庫存 | 隨機一種自然食物庫存 +1 |
| 移動速度 | 初始速度 ×（1 + 纖維加成）；GM 模式下為初始速度 + 纖維加成 |
| 蛇身前進間隔 | 460ms / 目前移動速度；緩速期間間隔 ×2 |
| 基礎攻擊延遲 | 2000ms / 攻擊速度倍率 |
| 小招延遲 | 基礎攻擊延遲 × 0.31 |
| 小招冷卻 | 2400ms / 冷卻倍率 × 0.29 |
| 大招冷卻 | 依角色設定；未設定者使用 2400ms / 冷卻倍率 |
| 爆炸半徑 | 2 × 蛋白半徑倍率 |
| 小招半徑 | max(1, 爆炸半徑 - 1) |
| 基礎傷害倍率 | 2 + 脂肪傷害加成 |
| 小招傷害 | 基礎傷害倍率 × 2.5 |
| 大招基準傷害 | 基礎傷害倍率 × 5；角色大招再套用各自倍率 |
| 圓形傷害模式 | 依六角距離線性衰減：damage × clamp(1 - distance / radius, 0, 1) |
| 身體暈眩率 | 15%，每點碳水 +1%，最多額外 +20% |
| 頭部暈眩率 | 30%，每點碳水 +2%，最多額外 +40% |
| 暈眩時間 | 500ms 暈眩，接著 500ms 緩速 |
| 控制打斷 | 暈眩與麻痺會移除尚未命中的招式；打斷不重置該招式冷卻 |
| 撞擊懲罰 | 撞敵方：2000ms 暈眩 + 1000ms 緩速；撞自己：懲罰加倍 |
| 撞擊落敗 | 累積撞擊暈眩時間超過 8000ms 會落敗 |

## 食物加成

| 食物 | 代號 | 目前效果 |
| --- | --- | --- |
| 蛋白（紅色） | protein | 爆炸半徑倍率每點 +0.05，最多額外 +1.0；爆炸半徑由 2 最高到 4 |
| 脂肪（黃色） | fat | 傷害倍率基礎 2，每點 +0.1，最多額外 +2；基礎傷害倍率最高 4 |
| 纖維（綠色） | fiber | 移動速度倍率每點 +0.04，最多額外 +0.8；招式冷卻倍率每點 +0.05，最多額外 +1.0 |
| 碳水（藍色） | carb | 攻擊速度倍率每點 +0.05，最多額外 +1.0；同時提高身體/頭部暈眩率 |
| 蟠桃(雙色) | dual | 只會由均衡角色補出；顯示的兩種庫存各 +1，能量 +2 |
| 迷幻菇 | black | 蠱王可補出；隨機自然食物庫存 +1，能量 +3 |

## 食物生成與角色食補

| 角色類型 | 補出食物規則 | 吃食額外收益 |
| --- | --- | --- |
| 白龍 / 均衡 | 隨機自然食物；50% 機率補出蟠桃(雙色) | 吃任意食物時 20% 機率讓該食物相關庫存隨機 +1；吃迷幻菇時候選為四種自然庫存 |
| 蛋白/脂肪/纖維/碳水偏好角色 | 偏好食物權重 0.4，其餘自然食物各 0.2 | 吃到單色偏好食物時 50% 機率該庫存額外 +1；蟠桃不觸發 |
| 蠱王 / 迷幻菇 | 1/3 機率補出迷幻菇，否則補出隨機自然食物 | 吃迷幻菇時 1/15 機率隨機庫存 +2，否則另有 1/3 機率隨機庫存 +1；兩種加成不疊加 |
