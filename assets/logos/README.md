# Hex Snake Fresh Logo Concepts

這是重新設計的新一輪 12 款 logo，不沿用前一輪的六角盾牌、S 字蛇形、角色眼睛或吉祥物頭像構圖。設計理念是把六個 Q 版角色的共同點抽象成更簡潔的符號語彙：六段結構、節甲、角刺、羽片、鰭、鉗形、能量節點與六角棋盤方向感。所有 SVG 都是透明背景，並控制在 2 到 4 個顏色內。
